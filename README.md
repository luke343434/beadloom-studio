# 串拾 Beadloom Studio

一个可交互的串珠设计模拟器。用户可以从素材库拖入珠子、调整排列、独立编辑尺寸和颜色、多选批量操作，并导出 PNG 设计图。

## 主要功能

- 30 种内置珠子和配件，覆盖矿石、玉石、水晶、木质、琉璃、金属隔片和吊坠
- 内置素材使用本地保存的 Pexels 实拍照片，来源见 [`IMAGE_SOURCES.md`](IMAGE_SOURCES.md)
- 从素材库直接拖入手串，并精确插入两颗珠子之间
- 自定义类目、品种、材质、尺寸、颜色和配件形态
- 拍照或上传实物照片，自动裁切压缩后保存到个人素材库
- 可粘贴供应商单颗珠子图片直链，图片只保存在个人浏览器素材数据中
- 自定义素材通过 IndexedDB 保存在当前浏览器中
- 多选、批量复制、移动和删除
- 高分辨率 PNG 设计图和材料清单导出

## 本地运行

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
